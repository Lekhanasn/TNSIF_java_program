## 🏢 Project Module

### Shop Management Service
**Project:** Shopping Mall Management System

This module manages shop information in the shopping mall using **Java Spring Boot, REST APIs, Spring Data JPA, and MySQL**.

**Features:**
- Add a new shop
- View all shops
- View a specific shop by ID
- Update shop details
- Delete a shop
- Store and retrieve shop data from MySQL
- Test REST APIs using Postman

**Shop Details:**
- Shop ID
- Shop Name
- Owner Name
- Category
- Floor Number
- Contact
- Monthly Rent

**Architecture:**
```text
Postman
   ↓
REST Controller
   ↓
Service Layer
   ↓
Spring Data JPA Repository
   ↓
MySQL Database
